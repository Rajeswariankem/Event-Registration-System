# 🎉 Event Management System

A modern full-stack Event Management application developed using Spring Boot, HTML, CSS, and JavaScript with an interactive and responsive user interface.

---

## 🚀 Features

- Create and manage events  
- Register participants for events  
- Interactive toast notifications  
- Responsive and modern UI  
- Smooth animations and transitions  
- Real-time event updates  
- Cloud-hosted backend and database

---

# 🛠️ Technologies Used

## Backend

* Java
* Spring Boot
* Spring Data JPA
* Hibernate

## Frontend

* HTML
* CSS
* JavaScript

## Database

* Supabase

## Deployment

* Render

# ⚡ Functionalities

## 📌 Event Management

* Create events

* Delete events

## 👥 Participant Management

* Register participants for events
* Track participant registrations

---

# 🌐 REST API Endpoints

| Method | Endpoint                    | Description          |
| ------ | --------------------------- | -------------------- |
| GET    | `/events`                   | Fetch all events     |
| GET    | `/events/{id}`              | Fetch event by ID    |
| POST   | `/events`                   | Create event         |
| PUT    | `/events/{id}`              | Update event         |
| DELETE | `/events/{id}`              | Delete event         |
| POST   | `/events/{id}/participants` | Register participant |
